Our mission

Build faster by starting with less

DummyProject exists to prove that you don't need a 300-package dependency tree to ship a working product. We believe great software starts small, stays readable, and grows intentionally.

What we believe in

Three principles guide every decision we make.

◎

Zero waste

No runtime dependencies. No build step. No bundler. If something can be done with standard Node.js, that's how we do it.

⚡

Radical transparency

Every line of code is readable, deletable, and replaceable. There are no magic abstractions hiding from you.

∑

Tested by default

We ship tests alongside every module using Node's built-in test runner — no framework required, no excuses.

Our journey

A few milestones we're proud of.

  • 2023

    Zero to one

    Started as a weekend experiment: a static server, a user store, and a calculator — all in pure Node.js with not a single npm package.

  • 2024 Q1

    Signup flow ships

    Added the signup and login pages, a full scrypt-based auth flow, and the public landing page — still zero runtime dependencies.

  • 2024 Q3

    Test suite reaches 100% coverage

    Every exported function in calculator.js and userStore.js is covered by the built-in node:test runner.

  • 2025

    Dashboard, Profile & About

    Expanded the UI with three new pages — a live dashboard, a profile settings panel, and this very about page. Still. Zero. Dependencies.
